Privacy Policy

Last updated: 27 October 2026

Hermes Agent is a personal tool used only by its developer to access their own Google account.

Data accessed

With the user's consent through Google OAuth, Hermes Agent may access Gmail messages and other Google account data needed for the tasks the user runs.

How data is used

Data is used only to carry out actions the user requests. It is processed on the user's own devices and is not sold, shared with third parties, or used for advertising.

Storage

OAuth tokens are stored locally on the user's machine. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Hermes Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
